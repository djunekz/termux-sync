# Code of Conduct

## Our Standard

termux-sync is a small open source project. Participation is expected to be straightforward and professional. The standard is simple: treat other contributors, users, and maintainers with basic respect.

Behavior that is acceptable:

- Providing constructive feedback on issues and pull requests
- Disagreeing with a technical decision and explaining your reasoning clearly
- Asking questions about how the project works
- Pointing out mistakes or bugs without personal criticism

Behavior that is not acceptable:

- Insults, personal attacks, or dismissive language directed at any person
- Harassment of any kind, public or private
- Posting private information about someone without their consent
- Sustained disruptive behavior in issues, pull requests, or discussions

The standard applies regardless of experience level, background, or history with the project.

---

## Scope

This code of conduct applies to all project spaces: GitHub issues, pull requests, discussions, and any other communication associated with the termux-sync repository.

---

## Enforcement

Maintainers are responsible for enforcing these standards. If someone's behavior is unacceptable, maintainers may remove comments, close issues or pull requests, or block the individual from the repository.

If you witness or experience unacceptable behavior, report it by opening a private communication with a maintainer. You can use GitHub's private contact options or reach out through the contact information in the repository's About section.

Reports are handled discreetly. Retaliation against anyone who reports a conduct issue is itself a violation of this code of conduct.

---

## Intent

This document is not intended to be a bureaucratic rulebook. It exists to state clearly what the project expects so that contributors can focus on the work rather than managing interpersonal conflict. If you have a question about whether something is acceptable, the practical test is whether it would be considered professional and respectful in a collaborative work environment.
